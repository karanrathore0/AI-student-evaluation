2. Flowcharts

2.1 User Authentication Flow
This flowchart describes the login and registration process for both Students and Teachers.

flowchart TD
    Start([Start]) --> OpenApp[Open Application]
    OpenApp --> HasAccount{Has Account?}
    HasAccount -- No --> Register[Registration Page]
    Register --> SelectRole[Select Role: Student/Teacher]
    SelectRole --> InputDetails[Input Details]
    InputDetails --> SaveDB[(Save to Database)]
    SaveDB --> Login
    
    HasAccount -- Yes --> Login[Login Page]
    Login --> EnterCreds[Enter Credentials]
    EnterCreds --> Verify{Verify in DB}
    Verify -- Invalid --> LoginError[Show Error]
    Verify -- Valid --> CheckRole{Check Role}
    
    CheckRole -- Teacher --> TeacherDash[Redirect to Teacher Dashboard]
    CheckRole -- Student --> StudentDash[Redirect to Student Dashboard]


2.2 Teacher Evaluation Flow
Describes how a teacher evaluates a student by entering marks, which the system processes to generate a grade.

flowchart TD
    Start([Teacher Logged In]) --> ViewStudents[View All Students]
    ViewStudents --> SelectStudent[Select Student]
    SelectStudent --> AddMarks[Enter Marks for Subject]
    AddMarks --> Submit[Submit Data]
    Submit --> EvalLogic[System Evaluates Performance]
    EvalLogic --> CalcGrade[Calculate Grade]
    CalcGrade --> SaveResult[(Save Result to Database)]
    SaveResult --> ShowSuccess[Display Success Message]
    ShowSuccess --> End([End])


2.3 Student Dashboard Flow
Describes the student's perspective when they log in to view their performance.

flowchart TD
    Start([Student Logged In]) --> FetchResults[Fetch Results from DB]
    FetchResults --> HasResults{Results Found?}
    HasResults -- No --> ShowEmpty[Display "No Results Found"]
    HasResults -- Yes --> CalcAnalytics[Calculate Overall Analytics]
    CalcAnalytics --> DisplayMarks[Display Subject Marks & Grades]
    DisplayMarks --> DisplayRecs[Display Performance Recommendations]
    DisplayRecs --> End([End])

5. Algorithm / Pseudocode

Algorithm: Student Evaluation and Grading Logic

Input: 'subject' name and 'marks' out of 100 for a specific student.
Output: Computed 'grade' and dynamically generated AI recommendations.

1. START
2. RECEIVE student_id, subject, marks from Teacher Input
3. IF marks < 0 OR marks > 100 THEN
      RETURN Error "Invalid marks entered"
   END IF
4. COMPUTE Grade based on marks:
      IF marks >= 90 THEN 
         grade = "A+"
      ELSE IF marks >= 80 THEN 
         grade = "A"
      ELSE IF marks >= 70 THEN 
         grade = "B"
      ELSE IF marks >= 60 THEN 
         grade = "C"
      ELSE IF marks >= 40 THEN 
         grade = "D"
      ELSE 
         grade = "F" (Fail)
      END IF
5. GENERATE Recommendations based on grade:
      IF grade == "A+" OR grade == "A" THEN
         recommendation = "Excellent performance. Focus on advanced topics."
      ELSE IF grade == "B" OR grade == "C" THEN
         recommendation = "Good, but needs more practice in core concepts."
      ELSE
         recommendation = "Needs immediate attention and remedial classes."
      END IF
6. SAVE new Result object { student: student_id, subject, marks, grade } into Database
7. RETURN Success Message
8. END
